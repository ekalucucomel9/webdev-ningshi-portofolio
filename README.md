## Portofolio Web Surya Ningshi 🌟

Proyek ini adalah portofolio web dasar yang dibuat menggunakan HTML, CSS, dan JavaScript. Tujuannya untuk mempelajari struktur halaman, styling responsif, dan interaksi sederhana.

## Fitur Utama 💻
- Tema Dark/Light Mode
- Sapaan dinamis dengan JavaScript
- Desain responsif (Mobile–Desktop)
- Navigasi ke bagian Tentang, Keahlian, Proyek, dan Kontak

✦ Tema Dark / Light Mode  
   Memberi pengalaman visual yang nyaman sesuai selera pengguna.

✦ Sapaan Dinamis  
   JavaScript akan menyapa pengunjung sesuai waktu — pagi, siang, atau malam.
   Memberikan kesan hangat dan personal.

✦ Desain Responsif  
   Tata letak menyesuaikan secara mulus dari Mobile → Tablet → Desktop.

✦ Navigasi Halus & Terstruktur  
   Menu menuju:
      • Tentang  
      • Keahlian  
      • Proyek  
      • Kontak  
   Dibuat untuk pengalaman menjelajah yang lembut dan intuitif.
